# Learn C - Bài Tập (C Programming Exercises)

This repository contains a comprehensive collection of C programming exercises organized into 8 distinct parts. It is designed to help learners practice and master C programming step-by-step, starting from basic concepts and moving to more advanced topics.

## 📂 Repository Structure

The exercises are structured systematically into folders:

*   **Part 1 to Part 8:** Each part represents a different level or topic in C programming. Inside these directories, you will find subfolders for individual exercises (e.g., `1.1.ex1`, `2.1.ex10`, `bai36`).
    *   Each exercise subfolder typically contains a `main.c` file with the implementation for that specific problem.
*   **`Workbook [En].docx`:** This document contains the problem statements and instructions for the exercises.
*   **`ran_san_moi.c`:** A standalone implementation of the classic Snake game in C, demonstrating how to build a small interactive console application.
*   **`output/`:** A directory designated for compiled executable files and build artifacts.

## 🚀 Getting Started

1.  **Read the Workbook:** Open `Workbook [En].docx` to view the exercises and their requirements.
2.  **Navigate to an Exercise:** Browse the `PartX` folders to find the corresponding source code for an exercise.
3.  **Compile and Run:** Use a C compiler (like GCC) to compile the `main.c` file within an exercise folder. 
    ```bash
    # Example compilation
    gcc Part1/1.1.ex1/main.c -o output/ex1
    ```

## 🛠️ Requirements

- A C compiler (GCC, Clang, MSVC, etc.)
- A text editor or IDE (VS Code, Code::Blocks, CLion, etc.)
